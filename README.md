# 🚀 42 Málaga - Pool and Common Core Projects

Welcome to my repository dedicated to the **Pool** and **Common Core** projects completed at **42 Málaga** (Fundación Telefónica).

This repository serves as documentation for my learning progress and software development journey throughout the curriculum at 42 Málaga.

---

## 📌 About 42 Málaga

**42 Málaga** is a software engineering campus supported by **Fundación Telefónica**, based on an innovative learning methodology:
- **No teachers or traditional classes:** Learning is 100% hands-on, practical, and autonomous.
- **Peer-to-peer (P2P):** Collaborative and interactive learning driven by peer evaluations.
- **Gamification:** Skill-tree progression across levels by tackling increasingly complex projects in C programming, C++ OOP, system administration, algorithms, graphics, and web/network services.

---

## 📂 Common Core Projects

Below is the list of projects that make up the Common Core curriculum:

### 🟢 Circle 00
- **Libft:** Re-coding standard C library functions (`string.h`, `stdlib.h`, linked lists, etc.) to build a personal library used throughout future projects.

### 🟡 Circle 01
- **ft_printf:** Recreating the standard C `printf` function to handle variadic arguments (`va_list`) and format specifiers (`%c`, `%s`, `%p`, `%d`, `%i`, `%u`, `%x`, `%X`, `%%`).
- **get_next_line:** A function that reads and returns a full line from a file descriptor, efficiently managing static variables and memory allocation.
- **Born2beroot:** Setting up and configuring a secure Debian/CentOS Virtual Machine following strict security rules, LVM partitioning, sudoers, UFW firewall, SSH, and password policies.

### 🟠 Circle 02
- **push_swap:** An efficient sorting algorithm project using two stacks (`a` and `b`) to sort data using a limited set of operations with the minimal instruction count.
- **so_long / fract-ol / pipex:** (Selectable path)
  - *so_long:* A simple 2D game developed using textures and the MiniLibX graphical library.

### 🔴 Circle 03
- **minishell:** Writing a custom UNIX command-line interpreter (shell) in C, featuring built-in commands, pipelines, redirections, signal handling, and environment variable management.
- **Philosophers:** Solving the classic "Dining Philosophers" problem using threads, mutexes, and processes to understand concurrency and race conditions.

### 🟣 Circle 04
- **NetPractice:** Practical networking exercises covering IPv4 addressing, subnet masks, and routing tables.
- **cub3D / miniRT:** (Selectable path)
  - *cub3D:* A 3D game engine inspired by Wolfenstein 3D, built using Raycasting techniques.
- **CPP Modules (00 - 04):** Introduction to Object-Oriented Programming (OOP) in C++ (C++98 standard):
  - *CPP 00:* Namespaces, classes, member functions, std::iostream, initialization lists.
  - *CPP 01:* Memory allocation, pointers to members, references, switch statements.
  - *CPP 02:* Ad-hoc polymorphism, operator overloading, fixed-point number representation.
  - *CPP 03:* Inheritance, subobject initialization, shadow attributes.
  - *CPP 04:* Subtype polymorphism, abstract classes, interfaces, dynamic memory management in inheritance.

### 🔵 Circle 05
- **CPP Modules (05 - 09):** Advanced C++ concepts and Object-Oriented Programming:
  - *CPP 05:* Try-catch blocks, custom exception handling, nested class exceptions.
  - *CPP 06:* C++ type conversion operators (`static_cast`, `dynamic_cast`, `const_cast`, `reinterpret_cast`), serialization.
  - *CPP 07:* C++ templates (function templates, class templates).
  - *CPP 08:* Standard Template Library (STL) containers, iterators, generic algorithms.
  - *CPP 09:* Advanced STL data structures, container selection strategies, and algorithmic problem solving (e.g., Bitcoin exchange, Reverse Polish Notation, PmergeMe).
- **Inception:** Virtualization and containerization project using Docker. Building a multi-container infrastructure with Nginx, WordPress (with php-fpm), and MariaDB running in separate Docker containers managed via Docker Compose.
- **ft_irc / webserv:** (Selectable path)
  - *ft_irc:* Building a fully functional Internet Relay Chat (IRC) server in C++98, handling non-blocking network I/O with `poll()` or `select()`.

## 🛠️ Coding Norms & Quality

- **C Projects:** Fully compliant with **Norminette** (42 C Coding Standard).
- **C++ Projects:** Developed adhering to the **C++98 standard**, avoiding C-style functions where C++ alternatives exist, and adhering to strict Memory Leak management (RAII practices).
